# AI 产品线知识图谱 · 方法与结果

内容涵盖：预训练词嵌入语义分析、产品线知识图谱构建、跨公司布局对比三部分。

样本：42 家 A 股金融科技公司 2025 年报的「业务概要 / 核心竞争力 / 研发投入」三章节，
共 678 条候选句，其中 285 条通过全部过滤条件，进入证据集。

## 2. 短语级词嵌入与语义相似度

### 2.1 两路语义信号

| 信号 | 来源 | 作用 |
|---|---|---|
| `rerank_score_v1/v2` | 上游 step 4-2 的预训练 **cross-encoder 重排模型** | 句–标签相关性打分 |
| `lsa_cos` | 本步的**字符 n-gram TF-IDF → TruncatedSVD(96维)** | 句向量与方向原型向量的余弦 |

本步在离线环境下采用本地 LSA 构造稠密向量，未再次调用 BERT 权重。
两路信号的相关系数为 **−0.012**，近似正交，可作为相互独立的校验，
而非对同一模型偏好的重复计数。

> 如需替换为 BERT/Word2Vec 类模型，只需改写 `build_kg.py` 中的 `build_embeddings()` 与
> `embed_phrases()` 两个函数（返回 L2 归一化的稠密矩阵即可），下游逻辑不变。
> 可选模型如 `BAAI/bge-small-zh-v1.5` 或 `shibing624/text2vec-base-chinese`。

采用字符 2–4 gram 的原因是：中文无需分词，且对 `MaaS`、`RAG`、`AIOps`、`妙想大模型`
这类新词与中英混排缩写表现稳定，而基于词典的分词会将其切分。

### 2.2 方向原型向量（短语级）

每个方向的原型向量 = 该方向全部 **CORE 关键词短语**的嵌入均值。
编码单位为短语而非单词：`大语言模型`、`检索增强生成`、`多方安全计算`
作为完整短语参与编码，不被拆分为单字。

### 2.3 判别力验证

对每条证据句计算其与 18 个方向原型的余弦相似度，统计正确方向的排名：

| 指标 | 本方法 | 随机基线 |
|---|---|---|
| MRR | **0.636** | 0.16 |
| Top-1 | **47.2%** | 5.6% |
| Top-3 | **74.9%** | 16.7% |

三项指标均显著高于随机基线，表明短语嵌入具备方向判别力，
可作为锚点规则之外的独立信号使用。

### 2.4 融合权重

```
semantic_score = 0.5 × norm(reranker 分数) + 0.5 × norm(LSA 余弦)
edge_weight    = conf_weight × (0.4 + 0.6 × semantic_score)
conf_weight    = HIGH 1.0 / MEDIUM 0.6 / LOW 0.25
```

`edge_weight` 为图谱中边宽与节点大小的统一口径。

## 3. 知识图谱结构

**125 个节点 / 205 条边**，共四层：

```
关键词(66)  ──EVIDENCED_BY──  技术方向(10) ──ENABLES──  产品线(7) + 内部应用(1)
                                   │                        │
                              SUBSUMES                      │
                                   │                        │
                              技术簇(3)                      │
                                                            │
              公司(38) ──USES_TECH──┘  ──OFFERS_PRODUCT──────┘
```

五类边：

| 关系 | 数量 | 语义 | 权重口径 |
|---|---|---|---|
| `USES_TECH` | 69 | 公司应用某技术方向 | edge_weight 求和 |
| `OFFERS_PRODUCT` | 44 | 公司提供某产品线 | 同上 |
| `EVIDENCED_BY` | 66 | 方向由关键词证实 | 命中公司数 |
| `ENABLES` | 11 | 技术支撑产品线（同句共现） | 共现句数 |
| `SUBSUMES` | 10 | 技术簇包含方向 | — |
| `APPLIES_INTERNAL` | 5 | 公司内部提效应用 | edge_weight 求和 |

每条 `USES_TECH` / `OFFERS_PRODUCT` 边均携带 `quote` + `section` + `page` 三个字段，
可回溯至年报原句与 PDF 页码；在交互页面中点击任意边，右侧「原文出处」面板即显示该边依据。

导出格式：`kg_nodes.csv` / `kg_edges.csv`（通用）、`ai_product_kg.graphml`
（可导入 Gephi 或 Neo4j `apoc.import.graphml`）、`kg_data.json`（前端）。

## 4. 公司 AI 技术栈核心方向

`company_tech_stack.csv` — 32 家可归类技术栈的公司。

核心方向判定 = 0.75 × 标签证据强度（归一化）+ 0.25 × 公司向量对方向原型的余弦。
以证据强度为主项：语义余弦易受长句与高频词影响，此处仅用于打破并列。

**技术栈深度前 10 家**

| 公司 | 核心方向 | 次级方向 | 广度 | 深度 | HHI |
|---|---|---|---|---|---|
| 科蓝软件 | 大模型 | AI工程化 | 3 | 9.34 | 0.49 |
| 同花顺 | 大模型 | AI工程化 | 2 | 9.16 | 0.97 |
| 东方财富 | 大模型 | AI工程化 | 4 | 7.45 | 0.69 |
| 新致软件 | 大模型 | 智能语音 | **6** | 6.25 | 0.42 |
| 中科金财 | 大模型 | 计算机视觉 | 3 | 5.12 | 0.44 |
| 长亮科技 | 大模型 | 智能决策 | 3 | 4.64 | 0.65 |
| 银之杰 | **计算机视觉** | 机器学习 | 4 | 3.72 | 0.58 |
| 赢时胜 | 大模型 | 机器学习 | 2 | 3.31 | 0.83 |

三个指标的口径：

**HHI** = 强度分布的集中度，取值 1.00 表示全部强度集中于单一方向。

## 5. 跨公司对比

### 5.1 关于资产 / 盈利维度

所用年报章节不含资产负债表与利润表数据，本包亦未附财务表，
因此以**业务属性**与**上市板块**作为规模与商业模式的代理变量。

如需按资产、盈利维度分组，可执行：

```python
fin = pd.read_csv("financials.csv")           # company_id, 总资产, 归母净利润, 研发费用...
st  = pd.read_csv("company_tech_stack.csv")
df  = st.merge(fin, on="company_id", how="left")
df["asset_tier"] = pd.qcut(df["总资产"], 3, labels=["小","中","大"])
df.groupby("asset_tier")[["stack_breadth","stack_depth","hhi"]].mean()
```

`company_tech_stack.csv` 中的 `company_id` 为标准 Wind 代码，可直接连接财务表。

## 6. 主要结果

**① 核心方向高度集中于大模型。**
32 家有技术栈的公司中，26 家的第一核心方向为大模型；`大模型` 一词覆盖 31 家、174 句；
该方向节点权重 53.1，为第二位（智能投研 11.8）的 4.5 倍，度中心性 0.29、
介数中心性 0.39 均居首位。它在图谱中是主要枢纽节点，同时区分度较低。

**② 组间差异主要体现在次级方向。**
金融IT服务商的次级方向偏向计算机视觉（票据、印鉴、影像识别）与 AI 工程化（算力、信创适配）；
互联网金融信息平台偏向智能投研与智能客服；支付类公司集中于智能决策（风控），HHI = 1.00。
次级方向的组间可分性高于第一方向。

**③ 持牌机构的披露量低于科技类公司。**
证券平均 1.2 条证据句、银行 2.0 条，对比金融IT服务商 9.9 条、互联网平台 20.0 条。
该差异可能来自披露动机与实际投入两方面，仅凭年报文本无法区分。
**图谱刻画的是已披露的 AI 能力，不宜直接读作技术实力。**

**④ 长尾技术方向覆盖稀疏。**
隐私计算 2 家、强化学习 3 家、知识图谱 3 家、NLP 3 家。
`联邦学习`、`同态加密`、`RLHF`、`图神经网络` 在 678 条候选句中零命中。
隐私计算的披露密度约为大模型的 1/65，与金融业的数据合规要求形成对照，可作为后续讨论方向。

## 8. 局限

1. **嵌入模型的粒度。** 96 维 SVD 的累计解释方差为 30.8%，语义粒度弱于预训练语言模型。
   原型检索 Top-3 达 74.9%，可满足本步的判别需求；替换为 bge-small-zh 等模型后仍有提升空间。
2. **`ENABLES` 边基于同句共现推断**，共 11 条。同句共现不等于因果支撑，且会遗漏跨句表述。
   在当前样本量下，该类边仅作定性参考。
3. **LOW 置信度证据已计入图谱**（权重 0.25）。若采用更严格口径，
   可在 `build_graph()` 中加入 `ev = ev[ev.confidence != "LOW"]`，代价是节点数减少约三成。
